## Featured Projects

### EMS Workflow System

Full-stack operational workflow system for EMS-style call intake, patient lookup, employee tracking, crew planning, role-based access, and supervisor analytics.

Built from real EMS dispatch and operations experience, the project focuses on practical workflow needs such as incomplete information, scheduling pressure, crew coordination, employee records, and supervisor visibility.

**Tech:** React, JavaScript, Python, Flask, SQLAlchemy, SQLite, Bootstrap, REST API

**Key features:**

* Role-based access for admin, supervisor, dispatcher, and HR workflows
* Guided call intake with validation and quality scoring
* Patient lookup and duplicate prevention
* Call history with filters
* Employee management and certification tracking
* Crew planner and crew presets
* Supervisor analytics dashboard
* Modular Flask backend with SQLAlchemy models and REST routes

Repository: [github.com/AlehSitsko/ems-workflow-system](https://github.com/AlehSitsko/ems-workflow-system)
