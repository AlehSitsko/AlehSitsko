## Featured Project — EMS Workflow System

A substantial portfolio project: an EMS/NEMT operations platform built from firsthand dispatch and operations experience, engineered with a production-style architecture.

**Key engineering**

- Multi-tenant architecture with organization-scoped access and role-based authorization
- Authenticated field-level encryption (AES-256-GCM) with organization-scoped key management for sensitive data
- Realtime updates via Server-Sent Events, fanned across workers with Redis
- Containerized deployment: PostgreSQL, Redis, Gunicorn, and Nginx (Docker) — plus a standalone, offline-capable Windows desktop build (Electron + SQLite)
- Automated testing (pytest, Vitest, Playwright) with CI that applies database migrations and runs a full-stack smoke test on every push
- Workflow modules: call intake, live dispatch board, operational calendar & scheduling, crew planning, fleet, HR/time/payroll, tasks, notifications, and audit logging

**Stack:** React · Flask · Python · SQLAlchemy · PostgreSQL · Redis · Docker · Nginx · Electron

[Windows release](https://github.com/AlehSitsko/ems-workflow-system/releases/latest) · [Case study](https://alehsitsko.dev/#/ems) · [Repository](https://github.com/AlehSitsko/ems-workflow-system)

> Portfolio project — not intended for real medical use and not to be used with real patient data.
